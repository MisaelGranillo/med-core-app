6Correlación clínica

Enfermedades lisosomales (Gaucher, Tay-Sachs): falta una hidrolasa y el sustrato se acumula dentro del lisosoma.

Enfermedades mitocondriales: el ADN mitocondrial se hereda por vía materna; afectan sobre todo músculo y cerebro.
